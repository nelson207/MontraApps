# Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Light / Dark / System appearance for all Montra apps.

**Architecture:** `ThemeState.mode` → `useApplyTheme` resolves it (OS media query for system) and
sets `data-bs-theme` + mode-specific `--app-*` variables; SCSS maps tokens per mode.

**Tech Stack:** React 19, Redux Toolkit, Bootstrap 5.3 color modes, SCSS, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-14-dark-mode-design.md`

## Global Constraints

- Default mode `system`; stored values other than `light|dark|system` fall back to `system`.
- Main colour unchanged across modes; text use of it must reach 4.5:1 on the mode's body background
  (light `#ffffff`, dark `#212529`, Bootstrap's `$body-bg-dark`).
- No new dependencies.

## Review Focus

- System mode + OS switch while the app is open → page follows without reload (manual).
- A very dark main colour (Graphite `#1f2937`) as link text in dark mode → lightened, readable (`readableOnDark` test).
- Saved preferences from before this feature (no `mode`) → system (`initialTheme` test).
- Custom content text colour set in light → not applied in dark (manual screenshot).
- Login page (before sign-in) honours the stored mode (manual).

### Task 1: Mode model
Files: `themeSlice.ts` (+`mode`, `setThemeMode`), `themeUtils.ts` (`ThemeMode`, `resolveMode(mode, prefersDark): "light"|"dark"`, `readableOnDark(hex)`, `applyThemeVariables(theme, resolved)`), `useApplyTheme.ts` (matchMedia listener), tests `themeUtils.test.ts`.
Tests: `resolveMode("system", true) → "dark"`, `("light", true) → "light"`; `contrastRatio(readableOnDark("#1f2937"), "#212529") >= 4.5`; `readableOnDark("#f5b301")` unchanged.

### Task 2: Token mapping
Files: `platform/styles/theme.scss` — light/dark blocks for subtle tints, link/emphasis colours, body colour only in light.

### Task 3: Switch UI
Files: `ThemeSettings.tsx` (segmented control + note on content text), `UserMenu.tsx` (3 buttons).

### Task 4: Feature pass
Files: insights.scss (dark viz palette), layout/news/results/forms/phoneinput scss, app stylesheets, light-only classes in TSX. Screenshot each screen in both modes and fix.

### Task 5: Verify
Lint, tests, five builds, screenshots.
